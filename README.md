# 🎓 Student Performance Analysis

This project focuses on analyzing the key factors that affect students' exam performance.  
The dataset includes variables related to study habits, attendance, parental involvement, and other academic and environmental aspects influencing student success.

---

## 📊 Dataset Overview
The dataset contains information on:
- Study time and learning habits
- Attendance and class participation
- Parental support and involvement
- Exam scores and overall academic performance

---

## 🎯 Objective
The primary goal of this project is to identify the most influential factors affecting student performance and to analyze their impact on exam results.

---

## 💡 Use Cases
- Educational analytics
- Data science and machine learning projects
- Academic research
- Developing strategies to improve student performance

---

## 🧪 Methods
The project applies:
- Exploratory Data Analysis (EDA)
- Data visualization techniques
- Statistical analysis methods

---

## 📁 Dataset Source
The dataset used in this project is publicly available and was obtained from Kaggle:

🔗 **Dataset Link:**  
https://www.kaggle.com/datasets/lainguyn123/student-performance-factors

This dataset covers academic and environmental factors affecting student performance and is intended for educational and research purposes.

---

## ℹ️ Note
This project is created for educational and analytical purposes only.
